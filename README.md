# mpires.dev

Personal portfolio and blog of Matheus Pires — Fullstack Developer.

Built with [Next.js 16](https://nextjs.org), [coss/ui](https://coss.com/ui) components, [Keystatic](https://keystatic.com) CMS, and [Tailwind CSS v4](https://tailwindcss.com).

## Getting Started

```bash
npm run dev
```

Open [http://localhost:4000](http://localhost:4000).

## CMS

Content is managed via Keystatic at `/keystatic`. In development, content is stored locally in `content/` and `public/images/`.

## Tech Stack

- **Framework**: Next.js 16 (App Router, Turbopack)
- **UI Components**: coss/ui (Base UI + Tailwind CSS v4)
- **CMS**: Keystatic
- **Content**: Markdoc
- **3D Background**: Three.js + React Three Fiber
